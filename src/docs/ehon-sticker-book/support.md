# えほんシール帳

読み聞かせた絵本の表紙を撮ると、その本だけのシールになる、iPhone・iPad のアプリです。読んだ本を毎日記録でき、読み返すたびにシールがキラキラに育ちます。

対応：iPhone・iPad（iOS 18 以降）

## よくある質問

### 無料で使えるのは何冊までですか

15冊までは無料で記録できます。15冊に届いたあとも、それまでの本の「また読んだ」は記録できます。16冊目からは、ずっとプラン（480円・買い切り）で何冊でも記録できます。月額の支払いはありません。

### 機種変更したら、ずっとプランはどうなりますか

新しい端末で、設定の「プラン」から「購入を復元」を押してください。同じ Apple ID で購入していれば、追加の支払いなしで使えます。

### 機種変更したら、記録はどうなりますか

記録は端末の中に保存しています。iPhone のバックアップから新しい端末に移すと、記録もいっしょに移ります。

### 家族と同じシール帳を使うには

設定の「家族で共有」から始めて、QR コードかリンクで家族を招待します。始める人がずっとプランを購入すれば、招待された家族は無料で参加できます。家族はそれぞれの Apple ID で参加します。参加すると、その端末にあった記録は家族の記録に置きかわります。

### 記録のお知らせが届きません

設定の「記録の お知らせ」がオンになっているか確かめてください。オンなのに届かないときは、iPhone の「設定」→「通知」→「えほんシール帳」で通知が許可されているか確かめてください。その日にもう記録していれば、お知らせは出ません。

### 表紙がうまく撮れません

明るい場所で、表紙の全体が画面に入るように撮ってください。表紙が見つからないときや位置がずれたときは、四隅を指で合わせられます。手が離せないときは題名だけで記録して、表紙はあとから撮ることもできます。

### まちがえて記録しました

記録タブで、その日の本を長く押すと出るメニューから消せます。
